PRIVACY PROTOCOL

THE LAST SERVER is an interactive fictional mystery game published by Zyvora.

Local gameplay data

This free static build stores progress and preferences in your browser using localStorage. It may include collected evidence, memories, choices, endings, language preference and local settings. The game does not automatically upload this data to a cloud service.

Save backups

Save Management can export a JSON backup or import a file you select. These files stay under your control; keep them private if they contain personal notes.

Hosting and online features

The website is delivered by GitHub Pages. This build does not provide user accounts, cloud saves, multiplayer, payments, or a custom analytics backend. Do not enter passwords or sensitive personal information into the in-game terminal.

Delete your progress

Use Settings → Save / Export → Reset All Local Progress, or clear site storage in your browser. Export a backup first if you may want to restore your save.

Contact and source

Report bugs at the GitHub issue tracker. View the source repository.
