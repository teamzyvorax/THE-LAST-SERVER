# THE LAST SERVER — Privacy

THE LAST SERVER is a fictional interactive game published by Zyvora.

## Local game data
The static GitHub Pages build stores gameplay progress and preferences in your browser's `localStorage`. This includes collected evidence, memories, choices, endings, language preference, and local settings. The game save does not automatically upload to a server.

## Save files
The Save Management panel can export a JSON backup or import one selected by the player. Exported files remain under your control. Treat them as private if you add personal notes.

## Network and hosting
The website is delivered by GitHub Pages. Your browser must request static assets from the host to load the game. This version does not implement user accounts, cloud save, multiplayer, payments, or a custom analytics backend.

## Deleting progress
Use Settings → Save / Export → Reset all local progress, or clear this site's browser storage. Export a backup first if you may want to restore your progress.
